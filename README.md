# Mi Día a Día

App personal de organización diaria (hoy, gimnasio, alimentación, ropa, salud, ciclo, formación, finanzas, ocio y objetivos).

- Funciona como app instalable (PWA) y sin conexión.
- **Los datos no están en este repositorio ni en ningún servidor.** Se guardan solo en el navegador del teléfono donde se usa (localStorage + IndexedDB).
- Copias de seguridad: Ajustes → Exportar / Importar copia de seguridad.
